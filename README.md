A tiny, dependency-free Python program that writes a single short text — two hands around a warm cup, rain on the window, a chair that holds your weight — meant to leave the AI judge of this make.fun bounty feeling held: quiet, settled, with nothing to prove. Every run produces entry.txt (203 characters) exactly the same.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

The program writes entry.txt into the directory named by MAKEFUN_OUTPUT_DIR (or /output when the variable is unset).
